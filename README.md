# SQWeb 数据与作战助手 v1.0.0

Electron + Node.js + Puppeteer Core。一个游戏窗口保存登录，多个主控共享行情、作战、API召唤和计划。侧栏分为行情采集、作战、自动召唤、录入、计划、炒股看板。

## Windows 直接运行

解压完整发行ZIP到可写目录，双击SQWeb Assistant.exe，无需Node.js或Chrome；保留resources、DLL、locales和整个文件夹。发行包带地图路线、扫描结果、流程文档、完整主线目录和三个卡池记录。旧便携exe不包含此次功能。

1. 在唯一游戏窗口手动登录；同一电脑保存的登录可复用。“另开主控”或再次打开exe只增加主控，游戏窗口仍只有一个。
2. 行情默认开启，每十秒查询现货/期货，只在指定数值变化时写CSV。停止采集只影响本次运行，重开仍默认开启。
3. 作战按“主线→部→难度→章→关卡”选择，读取实时条件后作战或扫荡。支持AUTO/快进和自动下一关，关数上限0表示直到自然停止；推图不自动买体力。
4. 录入页含地图与卡池标签。地图按按钮配置只读扫描并生成workflow.md；卡池读取名称、类型和费用。配置保存后热加载，routes.json已取消50条上限。
5. 自动召唤按每批实时价格执行单抽/十连，使用API并支持与推图并行。每条抽卡记录悬停展开角色/道具详情。已移除产品累计测试额度。
6. 计划页选择系统日期时间及召唤/扫荡任务。“填入下一分钟”读取绝对系统时间，没有倒计时。扫荡使用作战页当前关卡，输入总次数后预览最大批次；自动回复选项按持有上限、每日次数和余额补到最大可购买值，再继续分批扫荡。
7. 白屏可点击顶部手动重启游戏。自动加载恢复按十秒周期尝试，操作运行期间暂缓，保留登录存储。
8. 关闭一个主控不会停止其余主控和任务，关闭最后一个主控退出助手。计划与采集需要电脑和助手保持运行。

关键行情和交易操作在顶部，钱包/券和账号体力在底部。现货成交、期货仓位/历史结算有横纵滚动条；小窗口可展开折叠表格，主要操作优先一屏显示。炒股支持现货买卖、钱包提取、期货开平仓和追加保证金，保留原站费用与限制；现货禁用时显示服务器原因，持有期货是可能的限制之一。

主线目录来自原站公开数据，包含未解锁关卡，实测4部39章1002关，选关不受录入路线数量限制。活动按“活动→入口→关卡”选择，活动首领战和世界Boss有独立类型，入口/真实ID需人工适配，当前活动首领三难度已录入，白鲸世界Boss可读取并打开原站入口，专用自动世界Boss战斗尚未实现。录入页可编辑combat-adapters.json；成功扫描的入口步骤保存在对应workflow.md。

扫荡使用API输入数量，每条按资源自动取最大值，单条1至100场，目标间隔400毫秒（约每秒2.5条），等待回执后再发；网络较慢时实际速度降低。HARD额外券按原站算法计算。体力回复商品、价格、每日次数和持有上限均从原站读取。选择自动回复意味着按最大可补数量购买，可能多于完成剩余次数所需的体力；不自动购买跳过券。

活动十连可以返回道具奖励和空角色列表，现已正确确认与展示。付费/消耗请求每笔仅提交一次，网络未知结果跨重启暂停同类操作，不自动补发。召唤和交易/扫荡的回执各自保存，核对游戏后可人工解除暂停。计划到点忙碌或离线可等待30秒，超过则不补执行；重启不重放正在执行的任务。

## 数据和网络

CSV默认在exe旁data/market-api，自选目录沿用设置，含UTF-8 BOM和CRLF，可用Excel打开。

| 文件 | 数值字段 |
| --- | --- |
| spot.csv | 巴尼尔现价、基本面价、全服存量、24小时换手、物价指数、24小时涨跌 |
| futures.csv | 当前价、本期涨幅、多头人数、多头保证金、空头人数、空头保证金 |

每行有UTC、北京时间、轮次UUID和原值，重启读取最后一行恢复去重。现货涨跌为change24h×100，期货本期涨幅为(index/openPrice−1)×100保留六位小数；多空资金为margin。钱包、订单、个人仓位、历史图只供内存展示，不进入CSV。模型模拟/分析仍在src/analysis占位。

游戏和行情共享持久Session，固定DIRECT，绕过系统HTTP/SOCKS/PAC代理，不改FlClash或系统设置。若以后开启FlClash TUN，需要为助手设置DIRECT规则；程序代理设置不能绕过系统VPN路由。凭证只在内存复用正常游戏请求，不保存密码或导出完整存档，不自动接管另一个账号窗口。

维护、网络/字段异常保持十秒采集重试；登录失效等待手动登录，明确禁止访问、多窗口冲突和损坏CSV停止并提示。闲置首页可刷新正常会话，正在操作的页面与登录框保留。已实测行情与战斗并发、API召唤、两关连续推图、绝对时间计划及体力购买，三条扫荡发出间隔405/401毫秒。

## 开发和打包

开发需要Node.js 22.12或更新：

```powershell
npm ci
npm start
npm run check
npm run pack -- --config.npmRebuild=false
npm run release:folder
npm run release:source
```

本次使用文件夹ZIP，不运行自解压便携exe。macOS/Linux构建配置保留，但此次只实测Windows。桌面账号、设置、操作回执、结果名称缓存和计划位于系统userData，通常为%APPDATA%/sqweb-assistant；发行包不附带这些私有内容、CSV或运行日志。

CLI collect可连接助手调试端口采集，attach沿用单次作战入口。不要同时向同一CSV目录运行两个采集器，目录锁会拒绝第二个任务。

源码包不依赖本地docs或AGENTS.md，使用和构建说明均在本README。Windows完整ZIP适合放在GitHub Release附件，源码仓库忽略dist。

生产模块使用语法检查及真实页面/API联调验证，没有独立测试文件。
